# CBLP 局部不透明文本编织器

一个无需后端、无需依赖、可离线运行的单页 Web 工具。

## 使用

直接双击 `index.html`，或在目录中启动任意静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 功能

- 对中文分句进行有界局部换位
- 保留标点与可选的句首句尾
- 支持最大短片段长度 `k`、最大位移 `d` 和扰动强度
- 多候选随机搜索
- 强制破坏连续三字原文片段
- 可指定重点保护短语
- 启发式估计全文可读性、局部不透明度、最长原样连续片段和平均位移
- 枚举短窗口，展示风险最高的局部片段
- 本地复制和 TXT 下载

## 算法边界

这不是密码学，也不能阻止截图、人工重排、OCR 或语言模型恢复。当前评分是启发式指标，适合验证产品方向，不应被描述为安全保证。

下一阶段最值得增加的是：

1. 基于真实中文语料训练局部可恢复性评分器；
2. 人类阅读实验与参数标定；
3. Web Worker 并行搜索；
4. 对否定、数字、专名和固定搭配进行专项保护；
5. 输出多个 Pareto 候选供人工选择。
